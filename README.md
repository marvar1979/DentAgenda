# DentAgenda - Agenda para consultorios odontológicos

Proyecto frontend responsive construido con HTML5, CSS3, Bootstrap 5.3, Bootstrap Icons, JavaScript y JSON.

## Módulos incluidos
- Login y sesión local por roles.
- Dashboard general.
- Agenda y alta de citas.
- Filtros por fecha, estado y búsqueda.
- Pacientes y alta de pacientes.
- Tratamientos y seguimiento.
- Profesionales y especialidades.
- Pagos y caja.
- Inventario con alertas de stock.
- Reportes y exportación CSV.
- Configuración de clínica.
- Diseño responsive para móvil, tablet y escritorio.


## Dependencias externas
- Bootstrap 5.3.8 por CDN.
- Bootstrap Icons 1.13.1 por CDN.
- Fotografías profesionales desde Unsplash.



## Seguridad
Este proyecto es una demo frontend. Las contraseñas son visibles en el código y no existe backend ni base de datos real. Para producción se debe implementar autenticación segura, servidor, cifrado de contraseñas, autorización del lado servidor y una base de datos.
